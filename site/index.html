just-a-portal v{{VERSION}}

Send files between your computers over Tailscale.

Run it on each computer, open the browser tab it prints, pick a device and drop a file. The other computer clicks Accept. Files go straight between your devices over Tailscale; this site never sees them.

Run it

Needs Bun 1.4+ and the Tailscale app, connected, on both computers.

Each block makes its own folder, downloads portal.js, and runs it only if the checksum matches this build. --no-env-file stops Bun from loading a stray .env that could change the portal's settings.

macOS

mkdir -p ~/just-a-portal && cd ~/just-a-portal
curl -fsSLO https://portal.ruxera.com/portal.js
echo "{{SHA256}}  portal.js" | shasum -a 256 -c - && bun --no-env-file portal.js

Linux

mkdir -p ~/just-a-portal && cd ~/just-a-portal
curl -fsSLO https://portal.ruxera.com/portal.js
echo "{{SHA256}}  portal.js" | sha256sum -c - && bun --no-env-file portal.js

Windows (PowerShell)

mkdir -Force $HOME\just-a-portal | Out-Null; cd $HOME\just-a-portal
irm https://portal.ruxera.com/portal.js -OutFile portal.js
if ((Get-FileHash portal.js).Hash -eq '{{SHA256}}') { bun --no-env-file portal.js } else { 'Checksum mismatch: not running portal.js' }

About the checksum

SHA-256 of this build (also at portal.js.sha256):

{{SHA256}}

It catches a corrupted, partial or mismatched download. It is served from this same site, so it can't protect you if the site itself were compromised. For that, read portal.js before running it, or run from the source.

What it does

  • Tailscale required on both ends. It sends from this computer's Tailscale address to the other device's Tailscale address, so if Tailscale is down the connection fails instead of going out over your LAN.
  • Encrypted twice. Tailscale's WireGuard tunnel, plus a fresh AES-256-GCM key per transfer (X25519). Every 1 MiB chunk is authenticated and the file's SHA-256 is checked on both ends.
  • Your devices only. The receiver checks each sender with tailscale whois and, by default, only accepts devices owned by the same Tailscale user.
  • Nothing is overwritten. Files land in ~/Downloads/just-a-portal. If anything drops mid-transfer, the transfer stops and the partial file is deleted.
  • Local UI. The web page is served on 127.0.0.1 only, behind a session key printed in your terminal.
